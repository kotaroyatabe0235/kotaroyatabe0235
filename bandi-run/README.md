# バンディ・ラン（Bandi Run）

ブラウザだけで遊べる、クラッシュ・バンディクー風の3Dアクションゲーム。
**`index.html` をブラウザで開くだけ**で遊べます。インストールも、サーバーの起動も、ネット接続もいりません。

```
open index.html      # macOS
```

## 遊びかた

| そうさ | キーボード | タッチ（スマホ・タブレット） |
| --- | --- | --- |
| うごく | `← → ↑ ↓` または `W A S D` | 画面左半分をドラッグ |
| ジャンプ | `スペース`（長おしで高くとぶ） | 「ジャンプ」ボタン |
| スピンこうげき | `Shift` または `X` | 「スピン」ボタン |
| さいしょから | `R` | — |

- 木の箱をこわして、オレンジのくだものを集めながらゴールをめざします。
- 箱の上にとび乗るか、スピンこうげきでこわせます。
- 敵は上からふむか、スピンでたおせます。よこからぶつかるとミス。

## 箱のしゅるい

| 見た目 | なまえ | どうなるか |
| --- | --- | --- |
| 茶色 | 木の箱 | こわれる。ときどきくだものが出る |
| だいだい色（玉つき） | くだもの箱 | こわすとくだものが5こ出る |
| 赤 | TNT | 上に乗ると1.4秒後に爆発。まわりの箱も敵もふきとぶ（自分も当たる） |
| 銀色 | 鉄の箱 | こわれない。足場として使う |
| 黄色 | バウンド箱 | 乗るとすごく高くとべる。こわれない |

## ステージ

全1ステージ（およそ 210 マス）。とちゅうに白い旗（チェックポイント）が4つあり、
ミスをするといちばん近い旗からやりなおしになります。ライフは4つ。

## つくり

- **ライブラリを1つも使っていません。** three.js なども読み込まず、WebGL を直接たたいています。
  - 行列計算（`mul` / `perspective` / `lookAt` / `compose`）も自前
  - 形は立方体と球をプログラムで生成（`cubeVerts` / `sphereVerts`）
  - 主人公・敵・木は、すべて小さな立方体を組み合わせて作っています
  - 音は Web Audio API でその場で作っています（音声ファイルなし）
- 当たり判定は AABB（軸に沿った箱どうしのかさなり）。X・Y・Z を1軸ずつ動かして押しもどします。
- 1ファイル完結（`index.html` だけ）。オフラインでも動きます。
