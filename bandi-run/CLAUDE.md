# bandi-run について

ブラウザで遊ぶクラッシュ・バンディクー風の3Dアクションゲーム。
遊びかたは [`README.md`](./README.md) を参照。

## 大事な決めごと

- **外部ライブラリは使わない。** three.js も CDN も読み込まない。WebGL を直接使う。
  1ファイル（`index.html`）で完結させ、`file://` で開くだけで動く状態を保つ。
  （ES モジュールに分割すると `file://` で開けなくなるため、あえて1ファイルにしている）
- 画像・音声ファイルも持たない。形は立方体と球の生成コード、音は Web Audio API で合成する。

## ファイル構成

- `index.html` — ゲーム本体。上から順に「行列 → WebGL → 色 → 音 → 世界 → ステージ定義
  → 主人公 → 入力 → 当たり判定 → 更新 → カメラ → 描画 → ループ → 画面（UI）」の順に並んでいる。

## ステージのいじりかた

`buildLevel()` にステージのすべてが書いてある。使うヘルパーは次のとおり。

| 関数 | 意味 |
| --- | --- |
| `plat(x, z, w, d, top, color)` | 床。`top` は**上の面**の高さ |
| `crate(x, bottom, z, type)` | 箱。`type` は `wood` / `fruit` / `tnt` / `steel` / `bounce` |
| `fruit(x, y, z)` / `fruitArc(x, y, z, n, dz, h)` | くだもの（弧をえがいて並べる） |
| `enemy(x, y, z, x0, x1, spd)` | 左右を行ったり来たりする敵 |
| `mover(x, y, z, w, d, axis, range, spd, phase)` | 動く床。`axis` は `'x'` / `'z'` / `'y'`、上の面は `y + 0.5` |
| `checkpoint(x, y, z)` / `tree` / `rock` | 旗・かざり |

数字の目安（`GRAV=44, JUMP=15.2, SPEED=9.2`）:

- ジャンプの高さ **2.5マス**、とべる距離 **およそ5〜6マス**
- なので**すきまは2〜3マスまで**にする。ななめに跳ぶと速さが落ちて届かなくなるので、
  すきまの前後で足場の x をずらすのは 3マスくらいまで
- バウンド箱は `vy=22` → 箱の上から **5.5マス**上がる。
  ただしジャンプボタンを離すと追加の重力がかかるので、押しっぱなしにしたときの高さ。
  離したままだと 2.9マスしか上がらない

こわれない箱（`steel` / `bounce`）は `breakable()` で守られている。
先へ進むのに必要なバウンド箱が TNT やスピンで消えると進めなくなるため、この扱いは変えないこと。

## Artifact として公開したもの

iPad などからも遊べるように、Claude の Artifact にも同じゲームを置いてある。

- URL: https://claude.ai/code/artifact/a3272298-ba49-47a5-b44a-1a8ca505b62d
- Artifact は `<!doctype>` / `<html>` / `<head>` / `<body>` を書けないので、
  `index.html` から `<title>` ＋ `<style>` ＋ `<body>` の中身だけを取り出して公開している。
- **更新するときは、上の URL を `url` に渡して publish しなおすこと**（渡さないと別物ができる）。

## 動かして確かめる（ブラウザなし）

WebGL と DOM をにせもの（スタブ）に差しかえて、Node.js でロジックだけを走らせられる。
`index.html` の `<script>` の中身を取り出し、前にスタブを、後ろにテストをつないで実行する。

確かめたこと:

1. 例外なしで数千フレーム動くか、座標が NaN にならないか
2. ジャンプの高さ（2.5マス）と、地面の上で止まる高さ（y=0.75）
3. **ステージが最後までクリアできるか**（足場を順にたどる自動プレイでゴールまで到達するか）
4. カメラの行列（主人公が画面中央に来るか、カメラの後ろが `w<0` になるか、
   ワールドの +x が画面の左になるか）

ステージや物理の数字をいじったら、少なくとも 3 は流しなおすこと。
